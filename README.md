# sigcorp-frontend-challenge

> Resolver desafio de front-end com cobertura de testes, CI e padrões de código de equipe.

## Problema

Resolver desafio de front-end com cobertura de testes, CI e padrões de código de equipe.

## Solução

SPA React com Recoil, Material UI e Webpack, testes Jest e Cypress, Husky para hooks de commit e pipeline Travis CI com suporte a Docker.

## Stack

- React
- TypeScript
- Recoil
- Material UI
- Cypress
- Docker
